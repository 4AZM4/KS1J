# KS1J brand files

- `ks1j-logo.png`: the KS1J logo (1024 px, transparent outside the star): open hands holding the Jamaat inside an
  eight-pointed star with a double line. Its artwork follows the official KSI Jamaat Mumbai logo, so confirm the
  Jamaat is happy for it to be used before any public use.
- `wordmark.svg`, `wordmark-light.svg`: the letters KS1J (Atkinson Hyperlegible Bold) with a gold "1",
  for use beside the badge.

Where the logo is used: app icon, Android icons, splash and favicon (`apps/mobile/assets/images/`),
the website's icons (`apps/web/src/app/icon.png`, `apple-icon.png`) and header (`apps/web/public/brand/`),
the app's sign-in screen and receipts (`apps/mobile/assets/images/ks1j-logo.png`).
